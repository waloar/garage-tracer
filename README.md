# garage-tracer
Es un sistema basado en ML / MCPs que permite detectar una buena zona para comprar garages

## Demo web

La aplicación ahora incluye una interfaz web estática para buscar propiedades a partir de un prompt y filtros por localidad, provincia y rango de precios.

### Ejecutar localmente

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000` en el navegador.

### Validar filtros

```bash
npm test
```
